# Kompas 0.1.2 — update all with one password prompt

"Update all" asked for your password once for every package that had an update.
It now updates all packages from the same source in a single step, so you
authenticate once for system packages and at most once for Flatpak apps.

- Updates are grouped per source (system packages, Flatpak) into one transaction.
- The progress list shows one line per source, for example "Updating 23 packages
  from Ubuntu", instead of one line per package.
- If a grouped update fails, the error lists every package in that group.

Updating a single app from its details page works as before.

Download `kompas-amd64.deb` and `SHA256SUMS`. In that directory:

```bash
sha256sum -c SHA256SUMS
sudo apt install ./kompas-amd64.deb
kompas
```

The package replaces 0.1.1, any earlier release or preview and `cosmic-store`. Quit
Kompas before opening the new version. Tested by CI: formatting, clippy, workspace
tests, package replacement, metadata, X11 browsing and window shutdown, all against
the optimized binary. For Zorin 18 / Ubuntu 24.04, Intel/AMD 64-bit.

Known limits: no signed APT channel for Kompas itself yet; no integrated Epic/GOG
catalog or user review system. Native Linux flags do not guarantee hardware,
Proton or anti-cheat compatibility.
