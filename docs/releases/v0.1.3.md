# Kompas 0.1.3 — security updates

This release updates third-party libraries that GitHub flagged with security
advisories. There are no visible changes to the store itself.

- Updated `openssl`, `rustls` and `rustls-webpki` (secure connections) to patched
  versions.
- Updated `bytes`, `grid`, `rand`, `serde_with` and `time` to patched versions.
- Building Kompas from source now needs Rust 1.88 or newer.

One low-severity advisory remains: `lru` 0.12 comes from the pinned text renderer
used by the interface toolkit and cannot be raised without updating that toolkit.

Download `kompas-amd64.deb` and `SHA256SUMS`. In that directory:

```bash
sha256sum -c SHA256SUMS
sudo apt install ./kompas-amd64.deb
kompas
```

The package replaces 0.1.2, any earlier release or preview and `cosmic-store`. Quit
Kompas before opening the new version. Tested by CI: formatting, clippy, workspace
tests, package replacement, metadata, X11 browsing and window shutdown, all against
the optimized binary. For Zorin 18 / Ubuntu 24.04, Intel/AMD 64-bit.

Known limits: no signed APT channel for Kompas itself yet; no integrated Epic/GOG
catalog or user review system. Native Linux flags do not guarantee hardware,
Proton or anti-cheat compatibility.
