# Kompas 0.1.1 — optimized build

The package is now an optimized release build. v0.1.0 shipped an unoptimized debug
build, which made the first start and large searches noticeably slower.

- The installable package and its smoke tests now use `cargo build --release`.
- The website shows the current release and uses neutral wording instead of "preview".

No functional changes since 0.1.0: installing, updating and removing software work as
described in the 0.1.0 notes.

Download `kompas-amd64.deb` and `SHA256SUMS`. In that directory:

```bash
sha256sum -c SHA256SUMS
sudo apt install ./kompas-amd64.deb
kompas
```

The package replaces 0.1.0, any earlier preview and `cosmic-store`. Quit Kompas before
opening the new version. Tested by CI: formatting, clippy, workspace tests, package
replacement, metadata, X11 browsing and window shutdown, all against this optimized
binary. For Zorin 18 / Ubuntu 24.04, Intel/AMD 64-bit.

Known limits: no signed APT channel for Kompas itself yet; no integrated Epic/GOG
catalog or user review system. Native Linux flags do not guarantee hardware,
Proton or anti-cheat compatibility.
