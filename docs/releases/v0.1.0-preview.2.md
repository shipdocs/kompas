# Kompas 0.1.0 preview 2 — updates and window shutdown

This preview fixes system-package updates and closing Kompas on Zorin.

- System-package updates use PackageKit's pending update IDs rather than
  resolving only packages that are not installed.
- A stale update list reports that no pending update is available.
- Window-manager close requests follow the same shutdown path as the close button.
- After closing Kompas during an operation, the process exits when the last
  operation completes or fails. In-progress installations can finish safely.
- The desktop entry explicitly identifies Kompas's window class.

Download `kompas-preview-amd64.deb` and `SHA256SUMS`. In that directory:

```bash
sha256sum -c SHA256SUMS
sudo apt install ./kompas-preview-amd64.deb
kompas
```

The package replaces the previous preview. Quit Kompas before opening the new version.
Tested by CI: formatting, clippy, workspace tests, package replacement, metadata,
X11 browsing and a window-manager close request that must terminate the process.
This is a stripped debug preview for Zorin 18 / Ubuntu 24.04, Intel/AMD 64-bit.
Real-world system updates still depend on repository availability and authorization.

Known limits: no signed APT channel for Kompas itself yet; no integrated Epic/GOG
catalog or user review system. Native Linux flags do not guarantee hardware,
Proton or anti-cheat compatibility.
