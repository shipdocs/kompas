# Kompas 0.1.0 — first release

The first Kompas release in which installing, updating and removing software works.

**Important fix.** In the earlier previews (preview 1 to 3), installing, updating
and removing software from inside Kompas never started: the task stayed at 0%
without an error. This release fixes that. If you used a preview, update to this
package. System-package updates were confirmed on a real Zorin system.

Also since preview 2:

- No stray empty "winit window" in the taskbar.
- The package list from PackageKit is cached on disk, so the catalog is ready within
  a second after the first start instead of several seconds later.
- Zorin's extra software catalog loads even though its header repeats a key.
- Transactions subscribe to PackageKit's signals before starting, so a fast failure
  is shown as an error instead of a task that never finishes.
- Flathub statistics download with timeouts; caches moved to `~/.cache/kompas`
  (the old `~/.cache/cosmic-store` can be deleted).

Download `kompas-preview-amd64.deb` and `SHA256SUMS`. In that directory:

```bash
sha256sum -c SHA256SUMS
sudo apt install ./kompas-preview-amd64.deb
kompas
```

The package replaces any earlier preview or `cosmic-store`. Quit Kompas before opening
the new version. Tested by CI: formatting, clippy, workspace tests, package replacement,
metadata, X11 browsing and window shutdown. The package is still a stripped debug build
for Zorin 18 / Ubuntu 24.04, Intel/AMD 64-bit; release optimization is planned.

Known limits: no signed APT channel for Kompas itself yet; no integrated Epic/GOG
catalog or user review system. Native Linux flags do not guarantee hardware,
Proton or anti-cheat compatibility.
