Discover Steam games alongside local software. Open a game in Steam to install it, visit its store page or check ProtonDB.

Native Linux filtering is enabled by default. It checks published platform support, not your GPU, anti-cheat support or every game mode. Steam purchases and installation remain with Steam. Epic/GOG game catalogs are not yet integrated.

Install Kompas

Ready for your Zorin desktop.

Download the package, open a terminal in the Downloads folder and install it. Then open Kompas from your application menu.

Kompas is early software and still being tested. It does not replace Zorin Software. A previous cosmic-store package is replaced automatically, with legacy preferences preserved on first launch.

Clear about what works today.

Is this the official Zorin store?

No. Kompas is a ShipDocs project built on COSMIC Store. You can install Kompas on an existing Zorin system; inclusion in a standard Zorin installation requires agreement with the Zorin team.

Will every application and game work on my computer?

System packages are checked against enabled repositories and Flatpak catalogs use the host architecture. Steam native filtering uses Steam's published Linux flag. These checks cannot guarantee hardware requirements, Proton or anti-cheat compatibility. Steam discovery combines a featured selection with live search, rather than indexing the entire catalog.

What about ratings and reviews?

Available download counts help sort popularity within a source. They are not quality scores or comparable sales across stores. User reviews and Linux compatibility reports are planned; a review system is not implemented yet. Kompas does not inherit COSMIC Store ratings.

How can I help?

Try Kompas and report what you searched for, what you expected, what happened and your system details through the GitHub repository. Code contributions are welcome through pull requests. Read the store design review for the direction of the project.
